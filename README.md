# APS LOUNGE 체험판 (회원 · 메인관리자)

라운지포인트(LP)·인덱스포인트(IP) 통합 운영 기획의 화면 체험판입니다.
서버 없이 HTML 파일만으로 동작합니다.

## 파일

| 파일 | 화면 | 주소 (GitHub Pages) |
|---|---|---|
| `index.html` | 회원: 내 지갑, LP 교환(인덱스/풀팟 티켓), 내역, 풀팟 계정 연결 | `https://<계정>.github.io/<저장소>/` |
| `admin.html` | 메인관리자: 통합 현황, 풀팟 지급 확인, 정정 요청, 거래원장, 매장별 대조, 교환 정책, 매장·계정 | `https://<계정>.github.io/<저장소>/admin.html` |

## 올리는 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일 3개를 저장소 루트에 올립니다.
3. Settings → Pages → Branch를 `main` / `(root)`로 선택하고 저장합니다.
4. 1~2분 뒤 위 주소로 접속합니다.

## 예시 계정

- 메인관리자: `main_admin` / `admin1234`
- 회원: 로그인 화면의 예시 회원 선택, 또는 이름 + 휴대폰 (예: 김서연 / 010-2481-1024)

## 알아둘 점

- 데이터는 접속한 브라우저의 localStorage에만 저장됩니다. 다른 기기·다른 사람과 공유되지 않습니다.
- 같은 브라우저에서 `index.html`과 `admin.html`을 함께 열면 데이터가 연동됩니다.
  (회원이 티켓을 교환하면 관리자 화면의 풀팟 지급 확인에 바로 나타납니다.)
- 관리자 화면 상단의 "모의 풀팟 응답"으로 정상 / 응답 지연 / 지급 거절 흐름을 테스트합니다.
- "예시 데이터로 초기화"는 관리자 화면에 있습니다.
- 공개 저장소에 올리면 소스에 예시 비밀번호가 그대로 보입니다. 실제 운영 계정·회원 정보는 넣지 마세요.
  실제 운영에는 서버(API + DB)가 필요합니다.
- 교환 비율(100 LP = 1 IP, 4,000 LP = 티켓 1장)은 설명용 예시이며 확정 전입니다.
