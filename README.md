# APS POINT 체험판 (회원 · 관리자)

인덱스포인트(IP)로 풀팟 티켓을 교환하는 흐름을 보여 주는 화면 체험판입니다.
GitHub Pages에 올린 HTML 파일 두 개만으로 동작하며, 서버는 필요 없습니다.

## 화면

| 파일 | 화면 | 주소 |
|---|---|---|
| `index.html` | 회원: 포인트 조회, 풀팟 계정 등록, 티켓 교환, 내역, 체험용 테스트 시나리오 | https://teddy1986lee-gif.github.io/aps-point/ |
| `admin.html` | 관리자: 티켓 지급 내역(실패 처리·환불), 회원·포인트 관리, 포인트 직접/파일 등록, 설정 | https://teddy1986lee-gif.github.io/aps-point/admin.html |

## 예시 계정

- 관리자: `main_admin` / `admin1234` (또는 "체험 관리자 자동 로그인")
- 회원: 로그인 화면의 체험 회원 버튼, 또는 이름 + 휴대폰 (예: 김서연 / 010-2481-1024)

| 회원 | 상황 |
|---|---|
| 김서연 | 120 IP, 풀팟 계정 등록 — 바로 교환 가능 |
| 박도윤 | 40 IP, 풀팟 계정 등록 — 1장만 교환 가능 |
| 이하은 | 0 IP — 포인트 부족 |
| 최민준 | 80 IP, 풀팟 계정 미등록 — 계정 등록 후 교환 |

## 알아둘 점

- 데이터는 접속한 브라우저의 localStorage에만 저장됩니다. 다른 기기·다른 사람과 공유되지 않습니다.
- 같은 브라우저에서 두 화면을 함께 열면 서로 바로 반영됩니다.
  회원이 교환하면 관리자 지급 내역에, 관리자가 포인트·교환 조건·교환 열림/닫힘·이용 중지를 바꾸면 회원 화면에 나타납니다.
- 관리자 설정 → "예시 데이터로 초기화"로 처음 상태로 돌아갑니다.
- 파일 등록은 `회원번호, 포인트, 건번호` 열이 있는 CSV/XLSX를 받습니다(파일 등록 화면에서 예시 CSV를 받을 수 있음).
- 공개 저장소이므로 소스에 예시 비밀번호가 보입니다. 실제 운영 계정·회원 정보는 넣지 마세요.
- 교환 비율(40 IP = 티켓 1장, 1회 최대 5장)은 설명용 기본값이며 관리자 설정에서 바꿀 수 있습니다.

## 서버 버전 (`server/`, `public/`)

실제 운영용 서버(문자 인증, SQLite, 풀팟 API 연동)는 `server/`에 있습니다.

```
npm start            # 개발 서버
npm test             # 테스트
npm run build:demo   # 서버 코드를 묶은 단일 HTML 데모 → dist/aps-web-demo.html
```

`build:demo`는 `dist/`에만 씁니다. 위의 GitHub Pages 체험판(`index.html`, `admin.html`)은 건드리지 않습니다.
