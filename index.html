APS 포인트 교환간편 웹 버전 체험판 · 회원 웹사이트와 관리자 페이지

서버 코드가 이 브라우저 안에서 그대로 돌아가는 체험판입니다. 회원·연락처·풀팟 계정은 모두 예시이고, 실제 문자나 티켓은 나가지 않습니다. 바꾼 내용은 이 브라우저에만 남습니다.

체험 회원
관리자 계정 아이디 admin · 비밀번호 demo-pass-2026
모의 풀팟 응답
  1. 김민준으로 로그인해 풀팟 계정에 minjun_k를 넣으면 승인 없이 바로 연결됩니다.
  2. 티켓 교환에서 2장을 받으면 그 자리에서 지급 완료가 되고 포인트가 차감됩니다.
  3. 모의 풀팟을 응답 없음으로 바꾸고 1장 더 받으면 '지급 확인 중'이 됩니다. 관리자 티켓 지급에서 풀팟에서 확인을 누르세요.
  4. 관리자 포인트 등록 → 직접 등록에서 이름·휴대폰으로 회원을 만들고 포인트를 넣어 봅니다.
